FROM REQUEST TO REVIEW

A clear handoff, at every stage.

01 / START

Give the work a home.

Create a task from a clean repository. Relay gives it an isolated Git worktree and a place in your inbox.

codex-relay create
02 / CONTINUE

Pick up where you left off.

Run Codex locally, then resume the saved thread when you have an answer or more work to do.

codex-relay run <id>
03 / DECIDE

See what needs you.

Read the question, inspect the changes, and review recorded checks. You decide when the task is done.

codex-relay serve

Local work. Visible decisions.

The adapter runs through your local Codex authentication. The public preview uses sample data and never connects to your files or runs an agent.
